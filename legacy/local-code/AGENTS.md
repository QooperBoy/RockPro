# Kod historyczny — instrukcje dla agenta

Te źródła są wyłącznie archiwum do analizy. Aktywne wymagania są w głównym
AGENTS.md i docs/KUBA_HANDOVER.md. Nie uruchamiaj ani nie importuj zbiorczo
tego archiwum, nie podłączaj go do startu aplikacji i nie dodawaj do odkrywania
testów. Sondy mogą modyfikować CAD, instalację lub pliki na dawnych ścieżkach.
Nie przywracaj wycofanych parametrów liczności okuć. Oryginalne lokalne źródła
i dane zachowano. Przeniesienie funkcji z archiwum wymaga osobnej walidacji.
